* **Retro Linux Terminal Aesthetic:** Minimalist green-on-black hacker style, featuring standard terminal-like output and commands (`fetch`, `cat`, `ls`)[cite: 1].
* **Detailed Sections:**
  * `info` & `about` — Personal profile, interests, and focus areas[cite: 1].
  * `skills` — Core competencies in Cyber Security (OSINT, recon, network security), Web Development (React, TypeScript, Tailwind CSS), and Systems/Automation (Linux, Bash, Python)[cite: 1].
  * `experience` & `education` — Mentorship/volunteer background and academic timeline[cite: 1].
  * `certifications` — Earned credentials (FreeCodeCamp JS & Web Design, Generative AI)[cite: 1].
  * `projects` — Personal repositories and security tooling (`CTF_HELPER`, `Local_NetScan`, History website, etc.)[cite: 1].
  * `events.log` — Competition history and achievements in Cybersecurity (DefCamp CTF, National Cyber Security Olympiad) and Robotics[cite: 1].
